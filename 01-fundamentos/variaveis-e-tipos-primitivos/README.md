# Variáveis e tipos primitivos

**Status:** em estudo.

## Objetivo

Aprender a declarar, inicializar e utilizar variáveis em Java, compreendendo os principais tipos primitivos e o tipo `String`.

## Conteúdos

- [ ] Declaração e inicialização de variáveis
- [ ] `int` — números inteiros
- [ ] `double` — números decimais
- [ ] `char` — um caractere
- [ ] `boolean` — verdadeiro ou falso
- [ ] `String` — textos
- [ ] Exibição de valores com `System.out.println()`

## Prática

Os arquivos Java e exercícios deste assunto serão adicionados aqui conforme forem desenvolvidos.

## Critério de conclusão

Conseguir declarar variáveis dos tipos estudados, atribuir valores e exibi-los no console, explicando a finalidade de cada tipo.
