# Java Fundamentos

Repositório dedicado ao meu aprendizado da linguagem Java, do básico ao desenvolvimento de aplicações.

Meu foco é construir uma base sólida em lógica de programação e Java, registrando exercícios, exemplos e projetos pequenos conforme avanço nos estudos.

## Nível atual

**Em andamento:** fundamentos iniciais de Java.

Conteúdos já iniciados:
- Estrutura básica de uma classe e do método `main`
- Saída de dados com `System.out.println()`
- Variáveis e tipos primitivos
- Declaração e inicialização de variáveis

## Tecnologias e ferramentas

- Java
- IntelliJ IDEA
- Git

## Como executar

1. Clone ou baixe este repositório.
2. Abra a pasta do projeto no IntelliJ IDEA.
3. Abra o arquivo `.java` que deseja executar.
4. Execute a classe que contém o método `main`.

## Convenção de organização

- Cada assunto terá sua própria pasta quando fizer sentido.
- Exercícios devem ter nomes claros e objetivos.
- Os códigos serão publicados conforme forem desenvolvidos e compreendidos.
- Não serão adicionados conteúdos apenas para preencher o repositório.
